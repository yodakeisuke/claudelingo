# claudelingo

日本語 | [English](README.md) | [図つきの Web 版](https://claude.ai/artifact/JXNfv689sKeCfKoUmqm1Me#ja)

Claude Code にいつも通り指示を送るだけで、その指示の外国語版がすぐ下に出ます（初期設定は日本語 → 英語）。打ちながらの校正、返事の訳、単語のコアイメージの直感的な図解、読み上げと話す練習も、作業を止めずにその場で使えます。

- 指示も返事も一文字も変わらない
- 送信を待たせない
- 定額プランなら追加料金なし（プランの範囲内）

## はじめて使う

### 必要なもの

- Claude Code v2.1.287 以降（確かめ方：`claude --version`）
- ターミナルの `claude`、または Desktop アプリの Code タブ
- 読み上げを使うなら Mac

> [!WARNING]
> **本体とは別に、プランの使用量を使います**（API キーなら料金）。使うモデルは `/lingo` で変えられます。→ [Claude に送るもの](#claude-に送るもの) ・ [モデルの選び方](#モデルの選び方)

### 導入する

1. ターミナルで次の 2 行を実行します。

   ```bash
   claude plugin marketplace add yodakeisuke/claudelingo
   claude plugin install claudelingo@claudelingo
   ```

   `Successfully installed plugin: claudelingo@claudelingo (scope: user)` と出れば完了です。ターミナルにも Desktop にも入ります。
2. Claude Code を起動し直します（開いているセッションなら `/reload-plugins` でも可。Desktop は新しいセッションを始めます）。
3. 何か指示を送ります。数秒〜10 秒で、すぐ下に英語が出れば使えています。

> [!TIP]
> 英語以外を学ぶなら、`/lingo` で「学ぶ言語」を変えます（→ [設定を変える](#設定を変える)）。

### 画面のどこに何が出るか

```text
> test が fail してる原因を見て、直ったら refactor を続けて
  Look into why the **tests are failing**, …  🔊 🎤       ← 送った後の訳
  ┃ carry on  /ˌkæri ˈɒn/  [動く図解] …                   ← 単語の絵

● CI の Node のバージョンが古いのが原因です。
  🌐                                                      ← 返事の訳

お手本   carry on                       ✕                 ← 話す練習
[置換] Check why the test **is failing**, …   ✕           ← 入力中の校正
──────────────────────────────────────────
> check why the test is fail, 直ったら …                  ← 入力欄
──────────────────────────────────────────
```

ターミナルでの見え方です。Desktop でも並びは同じです。`**…**` は画面では太字です。

| 名前 | 出るとき |
|---|---|
| [送った後の訳](#送った後の訳) | 指示を送ったとき（自動） |
| [入力中の校正](#入力中の校正) | 入力欄で打つ手が止まったとき（自動） |
| [返事の訳](#返事の訳) | 返事の下の 🌐 を押したとき |
| [単語の絵](#単語の絵) | 訳の中の語を押したとき |
| [話す練習](#話す練習) | 🎤 を押したとき |

- 自動で出るのは「送った後の訳」と「入力中の校正」だけです。ほかは押したときだけ動きます。
- 🔊 は、押すとその文を読み上げます（→ [読み上げ](#読み上げ)）。設定と草は `/lingo` で開きます。
- ターミナルでボタンをクリックできるのは、全画面表示（`/tui fullscreen`）のときだけです（→ [表示される場所](#表示される場所)）。

## 機能の使い方

### 送った後の訳

**自動**　送った指示のすぐ下に、外国語での言い方と学びが出ます。

```text
> test が fail してる原因を見て、直ったら refactor を続けて    ← あなたの指示（そのまま送られる）
  Look into why the **tests are failing**, and once they pass,  🔊 🎤
  carry on with the refactor.                                ← 外国語版。** は直した所
  /lʊk ˈɪntu waɪ ðə tɛsts ɑr ˈfeɪlɪŋ …/                     ← 発音記号（🔊 を押すと出る）

  💡 ヒント                                                 ← 次に使える学び（母語で 1〜2 点）
  •  進行中の「落ちてる」は are failing。複数なら tests
  •  「直ったら〜を続けて」は once …, carry on with …
```

- 母語の部分は訳され、外国語で書いた部分は自然な形に直されます。
- 出るまで数秒〜10 秒かかります。その間は「訳しています…」の印が回ります。
- 右端の 🔊 で読み上げ、🎤 で話す練習。外国語版の語を押すと、単語の絵が開きます。

<details>
<summary>細かい決まり</summary>

| 場面 | 動き |
|---|---|
| 訳す指示 | 自分で送った指示（ターミナル・Desktop・Remote Control）。`/tmp を見て` のように `/` で始まっても、コマンドでなければ訳す |
| 訳さない | `/clear` などのコマンド、通知、ほかのエージェントやセッションからのメッセージ、オフの間に送った指示 |
| 長い指示 | 数十秒かかることがある（opus も同じ） |
| 貼り付け・コード | 訳では `[...]` になる |
| 改行 | なくなり、ひと続きで出る |
| 失敗したとき | 「訳せませんでした：理由」が出る。やり直しはできない（→ [表示から探す](#表示から探す)） |
| 同じ指示をもう一度送る | 今の設定で訳し直す |
| 消す・コピーする | 出ている訳だけは消せない。Desktop では文字を選べない |

</details>

### 入力中の校正

**自動**　送る前に、入力欄の上で外国語の言い方を確かめて直せます。言えない所は母語のまま打てば、訳して埋めます。

```text
[置換] Check why the test **is failing**, and once it passes,   ✕   ← 校正した文。** は直した所
       carry on **with** the refactor.                              ← 日本語の所（直ったら）は訳して埋める
       💡 進行中は is failing。is fail とは言わない                  ← いちばん大事な指摘
──────────────────────────────────────────────────────
> check why the test is fail, 直ったら carry on the refactor
                     ~~~~~~~                                        ← 誤りに赤い下線（前から 1 つずつ）
──────────────────────────────────────────────────────
```

1. 入力欄に打って、手を止めます。数秒で入力欄の上に帯が出ます。
2. 直すなら、次のどちらかです。
   - 赤い下線の語を自分で直す（身に付く）。直すと次の誤りに下線が移ります。
   - ［置換］を押す（速い）。入力欄が帯の文に丸ごと入れ替わります。元に戻すボタンはありません。
3. <kbd>Enter</kbd> で送ります。帯は消えます。帯だけ消すなら ✕ を押します。

<details>
<summary>細かい決まり</summary>

| 場面 | 動き |
|---|---|
| 帯が出るまで | 打つ手が「反応の速さ」（初期 1.5 秒）止まったら頼む。また打つと、その依頼は取り消す |
| 新しい帯が出るまで | 打ち始めると前の帯が薄くなって残る。次を頼んでいる間は帯の頭で印が回る |
| ［置換］が効かない | 帯の後に入力欄を変えたとき（「入力が変わったので置換しませんでした」と出る）。新しい帯を待ってから押す |
| コマンドを打っている間 | 校正しない（`/` の後がコマンド名の書き出しのとき） |
| 入力欄を空にした | 帯が消える |
| 通知などで送られた | 帯は残る（自分で送ると消える） |
| アンケートが出ている | 校正の帯も練習の帯も出ない |
| 練習の帯もあるとき | 練習の帯の下に出る |
| 失敗したとき | 帯に「訳せませんでした：理由」。また打つと頼み直す |
| ターミナルのキー | <kbd>ctrl</kbd>+<kbd>x</kbd> <kbd>tab</kbd> で帯へ、<kbd>Tab</kbd> で選んで <kbd>Enter</kbd>。たたむのは <kbd>ctrl</kbd>+<kbd>x</kbd> <kbd>ctrl</kbd>+<kbd>a</kbd> か `[-]` |

</details>

### 返事の訳

**🌐 を押す**　Claude の返事を段落ごとに訳して、訳のパネルに出します。返事そのものは変わりません。

```text
● CI の Node のバージョンが古いのが原因です。
    node-version: 18                            ← コードは訳さない
  20 に上げて、もう一度実行してください。
  🌐                                            ← 押すと訳のパネルが開く

┃ CI の Node のバージョンが古いのが…            ← 訳のパネル。最初の行はどの返事の訳か
┃ The cause is the old Node version on CI.      ← 段落ごとの訳
┃ Update it to 20 and run it again.
┃ 🔊                                            ← 外国語の側を段落の順に読む
```

1. 返事の下の 🌐 を押します。
2. 「訳しています…」の後、数秒〜数十秒で訳が出ます。
3. 閉じるときは、パネルの ✕ を押します（ターミナルは <kbd>ctrl</kbd>+<kbd>x</kbd> <kbd>x</kbd> でも）。

<details>
<summary>細かい決まり</summary>

| 場面 | 動き |
|---|---|
| 訳す向き | 主に母語の返事は外国語へ、主に外国語の返事は母語へ（自動） |
| 同じ返事をもう一度 | 訳し直さず、すぐ出す。失敗していたら訳し直す |
| 言語を変えた後 | 押すと、新しい言語で訳し直す |
| ほかの返事の 🌐 | パネルの中身が入れ替わる（一度に 1 つ） |
| 🌐 が無いまとまり | コードだけのまとまり |
| 語を押せるとき | 外国語への訳で、単語の絵がオンのとき |
| パネルの位置 | ターミナルは、全画面表示で幅 110 桁以上なら右、それ以外は入力欄の上 |
| `/clear` などの後 | パネルは開いたまま「返事の 🌐 を押すと、ここに訳が出ます」に戻る |
| 失敗したとき | 「訳せませんでした：理由」。🌐 を押し直すと訳し直す |

</details>

### 単語の絵

**語を押す**　訳の中の語を押すと、その語のコアイメージを動く図解で直感的に見られます。例文・類似表現・語源も開けます。

```text
  … and once they pass, carry on with the refactor.      ← carry を押す
  ┃ carry on  /ˌkæri ˈɒn/  🔊 🎤  [拡大]                  ← 押した語を含む句と、その発音記号
  ┃ [ 動く図解 ]                                          ← コアイメージの動く図解（Desktop）
  ┃ 点がじゃまを越えて、そのまま前へ進んでいく              ← 図解が示すこと（母語）
  ┃ [例文] [類似表現] [語源]                               ← 押すと下に開く
  ┃ Let's carry on after lunch.  🔊                        ← 例文と、その訳・使う気持ち
  ┃   お昼のあとも、そのまま続けよう。
  ┃   区切りが入っても、流れは止めない
```

Desktop での見え方です（図解は一例）。ターミナルでは図解の代わりに 1 行で出ます。

1. 訳の中の語を押します。押せる語は薄い字で出ています。
2. 「コアイメージを描画中…」（経過秒が進みます）の後、20〜60 秒ほどで出ます。待つ間も 🔊・🎤・［例文］などは押せます。
3. 閉じるときは、同じ語をもう一度押します。

<details>
<summary>細かい決まり</summary>

| 場面 | 動き |
|---|---|
| 句になるとき | 句の一部なら句で出る（carry → carry on）。句のどの語を押しても閉じる。ポインタを重ねると、句の語と絵の見出しが一緒に下線で光る |
| 押せる語 | 送った後の訳と、外国語への返事の訳。記号だけの所は押せない。濃い字は直した語と、開いている語 |
| いくつも押す | 押した順に下へ並ぶ |
| もう一度開く | 同じ文の同じ語なら、描き直さずすぐ出る（このセッションの間） |
| 同じ文面の指示が 2 つ | 押した方の下にだけ出る |
| ターミナル | 図解の代わりに 1 行（句・発音記号・一文・🔊 🎤）。［拡大］はない |
| ［拡大］ | 図解を大きくする。［縮小］で戻す（Desktop のみ） |
| ［例文］ | 場面の違う例文 3 つ。それぞれ訳と、なぜこの語かの一言つき。例文の 🔊 で発音記号も出る |
| ［類似表現］ | 言い換え 2〜3 個と、それを選ぶ場面 |
| ［語源］ | 部品の元の意味と、今の意味へのつながり。定説がなければ、そう書く |
| ［例文］などの開閉 | 「書いています…」の後、長くて 60 秒で出る。もう一度押すと閉じ、開き直すと書き直す（使用量も使う） |
| 単語の絵を閉じる | 開いていた［例文］なども閉じる |
| 失敗したとき | 「描けませんでした：carry」「書けませんでした」（→ [表示から探す](#表示から探す)） |

</details>

### 読み上げ

**🔊 を押す**　押した所の文を、Mac の声で読み上げます。

| 🔊 の場所 | 読むもの | 発音記号 |
|---|---|---|
| 送った後の訳の横 | 訳の文 | 訳の下に出る |
| 訳のパネルの下 | 外国語の段落を順に | 段落ごとに出る |
| 単語の絵 | 句 | もとからある |
| 例文 | その例文 | 例文の下に出る |
| 練習の帯の［🔊 お手本］ | お手本 | — |

- 声は `/lingo` の「声」で選びます（初期は Samantha）。英語以外なら、その言語の Mac の声の名前を入れます。
- 続けて押すと順番に読みます。途中では止められません。
- 読めないときは「読み上げできませんでした：理由」と出ます。

<details>
<summary>細かい決まり</summary>

| 場面 | 動き |
|---|---|
| 声の名前 | システム設定 › アクセシビリティ › リーダーと読み上げ（macOS 15 以前は「読み上げコンテンツ」）で確かめ、追加できる。空にすると既定の声 |
| 読んでいる間 | 🔊 の横で音の棒が動く。重ねて押すと ×2 のように待ちの数が出る |
| 発音記号 | 最初の 1 回だけ書く（「発音記号を書いています…」）。書けなければ消え、次に押すと書き直す |
| 音の出る所 | Claude Code を動かしている Mac |
| 長さ | 1 段落 4,096 字まで |

</details>

### 話す練習

**🎤 を押す**　お手本を声に出して言うと、伝わらなかった音と直し方をコーチが教えます。

> [!NOTE]
> **準備**：Mac の音声入力をオンにし、言語に学ぶ言語を加えます（システム設定 › キーボード › 音声入力）。マイクの音は claudelingo に届かず、使うのは書き起こした文字だけです。

```text
お手本    carry on  /ˌkæri ˈɒn/                ✕   ← 練習する文
練習      [Kerry on                 ] ?            ← 音声入力で話して Enter
聞き取り  Kerry on                                 ← 伝わらなかった語（Kerry）に赤い下線
💡 carry の a は「ア」寄り。「ケ」だと Kerry に聞こえる   ← 直し方（母語で 1〜3 点）
💡 on は弱く短く、carry と一息で
[🔊 お手本] [もう一度]                              ← お手本を読む／言い直す
────────────────────────────
>                                                  ← 入力欄（帯はこの上）
────────────────────────────
```

1. 送った後の訳か単語の絵の 🎤 を押します。入力欄の上に練習の帯が開きます。
2. 練習の欄へ移ります（Desktop は最初から。ターミナルは <kbd>ctrl</kbd>+<kbd>x</kbd> <kbd>tab</kbd>）。
3. 音声入力を始め、お手本を声に出して言います。
4. <kbd>Enter</kbd> を押します。数秒で、聞き取りと 💡 が出ます。

<details>
<summary>細かい決まり</summary>

| 場面 | 動き |
|---|---|
| 音声入力の始め方 | システム設定 › キーボード › 音声入力 にあるショートカット（fn キー 2 回など） |
| 欄が空で <kbd>Enter</kbd> | 何も起きない |
| キーボードで打った | 打った文をお手本と比べる |
| 閉じる | ✕、または同じ 🎤 をもう一度 |
| 別の 🎤 | 帯の中身が入れ替わる。届く前のコーチは捨てる |
| 欄の文の行き先 | 会話には入らない。コーチのため Claude に送る |
| claudelingo をオフ | 帯が消える |
| 失敗したとき | 「コーチできませんでした：理由」。もう一度 <kbd>Enter</kbd> |

</details>

### 草

**/lingo の下**　自分で書いた外国語の語数が、1 日 1 マスで並びます。GitHub の草と同じ見方です。

```text
6月      7月      8月        9月
· · · · · · · ▒ · · · ▒ · ░ · ▒ · ·
· ░ ░ · ░ ▒ · ░ ░ · · · ▒ ▒ ▒ ▒ █
· ▒ ▒ · ░ · · ░ ░ · ░ ▒ ░ ▒ · ▒ ░
· · · ▒ · · ░ ▒ ▒ ▒ ▒ ░ ░ · █ █ ▒
· ▒ ▒ · ░ ▒ · ▒ ░ ░ · · ░ ▒ ░ ▒ █
· · · · ░ · · · · · · · · █ ▒ █ █
· · · · · ▒ · · · · ▒ ▒ ░ · · ▒ ·
自分で書いた外国語 3,482 語                     ← これまでの合計
```

ターミナルでの見え方です（実際は緑の濃さ）。Desktop では 1 年分が 1 枚の絵で出ます。濃さ：`·` 0 語 ／ `░` 1〜99 語 ／ `▒` 100〜249 語 ／ `█` 250 語以上

| 数えるもの | 数えないもの |
|---|---|
| claudelingo がオンの間に、自分で送った指示 | `` ` `` で囲んだ所・コードブロック・貼り付け |
| その中のラテン文字の語（don't は 1 語） | `/clear` などのコマンド |
| ファイル名や URL の英字も | 日本語など、ラテン文字以外 |

> [!NOTE]
> 学ぶ言語がラテン文字以外（中国語・韓国語・ロシア語など）なら、その言語で書いた語は数えません。草に出るのは、ラテン文字の語だけです。

<details>
<summary>細かい決まり</summary>

| 場面 | 動き |
|---|---|
| 1 マスの日付 | その PC の日付。縦は日曜〜土曜、右端の列が今週 |
| 並ぶ期間 | ターミナルは幅に入るだけの週、Desktop は 1 年分 |
| 記録 | PC に残り、すべてのセッションの分を足す（ほぼ同時に送った分は、片方が数えられないことがある）。画面から消す方法はない（→ [残るもの・消えるもの](#残るもの消えるもの)） |

</details>

## 設定と管理

### 設定を変える

**/lingo**　初期設定（日本語 → 英語）のままでも使えます。

```text
claudelingo     ● オン  [オフにする]            ← 全体のオン・オフ
基本
  母語          Japanese                        ← 言語名（例：Spanish）
  学ぶ言語      English
  今のレベル    例: 技術文書は読める。…          ← 得意・苦手を自由に
  モデル        [haiku] [*sonnet*] [opus]       ← 訳などに使うモデル（* は選択中）
送った後の訳    ● オン  [オフにする]            ← 機能ごとのオン・オフ
入力中の校正    ● オン  [オフにする]
  モデル        [*haiku*] [sonnet] [opus]
  反応の速さ    速い [-] 1.5 秒 [+] 遅い         ← 何秒止まったら校正するか
単語の絵        ● オン  [オフにする]
  モデル        [haiku] [sonnet] [*opus*]
読み上げ
  声            Samantha                        ← Mac の声の名前
（草）自分で書いた外国語 3,482 語               ← 草
```

1. `/lingo` を送ります。Claude が作業中でも開けます。
2. 変えます。ボタンは押すと、文字の項目は <kbd>Enter</kbd> で保存されます。
3. <kbd>Esc</kbd> で閉じます。

- 次の訳から効きます。出ている訳は変わりません。
- この PC のすべてのセッション・プロジェクトで共通です。
- 保存できると、その設定の横に ✓ が少しの間出ます。保存できないと赤字で「保存できませんでした：理由」と出て、値は変わりません。

<details>
<summary>項目ごとの決まり</summary>

| 項目 | 決まり |
|---|---|
| 母語・学ぶ言語 | 空のまま <kbd>Enter</kbd> しても変わらない |
| 画面の言葉 | 母語が Japanese か 日本語 なら日本語。ほかの言語名にすると英語になる |
| 今のレベル | 訳・ヒント・図解・コーチの難しさがこれに合う。空欄なら伝えない |
| 基本のモデル | 送った後の訳・返事の訳・発音記号・コーチ・例文などに使う（→ [モデルの選び方](#モデルの選び方)） |
| 反応の速さ | 0.3〜2 秒。［-］［+］で 0.1 秒ずつ。範囲外は端に丸め、数でない入力は無視 |
| 声 | 空にすると Mac の既定の声 |
| オフにしたまとまり | 見出しだけになる。claudelingo をオフにすると、下の項目と草が隠れる |
| 文字の項目 | <kbd>Enter</kbd> を押さずに離れると保存されない |
| ターミナルのキー | <kbd>Tab</kbd> で項目を移り、<kbd>Enter</kbd> で押す・確定 |

</details>

### 止める・外す・更新する

| したいこと | すること | 結果 |
|---|---|---|
| 全部止める | `/lingo` › claudelingo［オフにする］ | すぐ止まる。出ている訳は残る |
| 一部だけ止める | その機能の［オフにする］ | その機能だけ止まる |
| 新しい版にする | `claude plugin update claudelingo@claudelingo` → 起動し直す | 新しい版で動く |
| 外す | `claude plugin uninstall claudelingo@claudelingo` → 起動し直す | 設定と草の記録は PC に残る |

<details>
<summary>止めたときの細かい動き</summary>

| 場面 | 動き |
|---|---|
| claudelingo をオフ | Claude を呼ぶのも語を数えるのも止まる。ボタンと単語の絵は隠れ、🌐・帯・草も出ない。［オンにする］で戻る |
| 送った後の訳をオフ | 新しい指示を訳さない。🌐 などは使える |
| 入力中の校正をオフ | 帯がすぐ消え、下書きを送らない |
| 単語の絵をオフ | 語が押せなくなり、開いている単語の絵も隠れる |
| 自動で更新する | 初期は自動更新されない。`/plugin` › Marketplaces › claudelingo › Enable auto-update で自動になる |

</details>

### Claude に送るもの

次のときに Claude を呼び、そのたびに使用量を使います。

| きっかけ | 送る文面 | 回数 |
|---|---|---|
| 指示を送る | その指示 | 1 回 |
| 打つ手が止まる | 入力欄の下書き（消した文も） | 止まるたび |
| 🌐 を押す | その返事（コードだけの段落は除く） | 返事ごとに 1 回 |
| 語を押す | その語と、ある文 | 新しい語ごとに 1 回（重め） |
| ［例文］などを開く | その語と、ある文 | 開くたび |
| 🔊 を押す | 読む文（発音記号のため） | 文ごとに初回だけ |
| 練習で <kbd>Enter</kbd> | お手本と練習の欄の文 | 1 回 |

- 送り先は、あなたの Claude Code と同じアカウントの Claude だけです。Claude との会話には入りません。
- 減らすには：モデルを haiku に／入力中の校正をオフ、または反応の速さを遅く／使わない機能をオフに。

### モデルの選び方

| モデル | 向き |
|---|---|
| haiku | 速く、使用量が少ない。訳や図解の質は下がることがある |
| sonnet | 速さと質の釣り合いがよい |
| opus | 質が最も高い。遅く、使用量も多い |

| `/lingo` の設定 | 使うところ | 初期 |
|---|---|---|
| 基本 › モデル | 送った後の訳・返事の訳・発音記号・話す練習のコーチ・例文など | sonnet |
| 入力中の校正 › モデル | 入力中の校正 | haiku |
| 単語の絵 › モデル | 単語の絵 | opus |

どれも、その系統の最新版を使います。

### 表示される場所

| | ターミナル（全画面表示） | ターミナル（クラシック表示） | Desktop |
|---|:-:|:-:|:-:|
| 訳・帯・パネル | ✓ | ✓ | ✓ |
| 訳と返事の下のボタン（🔊 🎤 🌐・語） | クリック | 押せない | クリック |
| 帯とパネルの操作 | クリック・キー | キー | クリック |
| コアイメージの図解・草の絵 | 文字 | 文字 | ✓ |
| ポインタを重ねたときの表示（ボタンの説明・句の下線） | ✓ | — | ✓ |

- 全画面表示は、入力欄が画面の下に固定される表示です。`/tui` で確かめ、`/tui fullscreen` で切り替えます（会話はそのまま）。
- 表示されない所：VS Code 拡張のチャット画面、`claude -p`、クラウドのセッション、Desktop の WSL セッション。VS Code の統合ターミナルなら使えます。
- Remote Control（スマホ・ブラウザ）から送った指示も訳され、PC 側の画面に出ます。

<details>
<summary>キーでの操作</summary>

| したいこと | キー |
|---|---|
| 帯やパネルへ移る | <kbd>ctrl</kbd>+<kbd>x</kbd> <kbd>tab</kbd> |
| 選ぶ・押す | <kbd>Tab</kbd> で選んで <kbd>Enter</kbd> |
| 入力欄へ戻る | <kbd>Esc</kbd> |
| パネルを閉じる | <kbd>ctrl</kbd>+<kbd>x</kbd> <kbd>x</kbd> |

</details>

### 残るもの・消えるもの

| もの | 残る期間 |
|---|---|
| 設定と草の記録 | PC に保存。すべてのセッション・プロジェクトで共通。claudelingo の入った Claude Code を 30 日以上起動しないと消える |
| 訳・単語の絵・発音記号・返事の訳・練習 | セッションの間だけ。`/clear`・`/resume`・`/branch`・起動し直しで消え、戻せない |

<details>
<summary>細かい決まり</summary>

| 場面 | 動き |
|---|---|
| 30 日の根拠 | Claude Code の `cleanupPeriodDays`（初期値 30 日） |
| いくつものセッションで使う | 設定は最後に変えたものがすべてに効く。草はすべての分を足す（ほぼ同時に送った分は、片方が数えられないことがある） |
| 会話の記録 | 訳や図解は Claude との会話の記録に入らない |

</details>

## 困ったとき

### 症状から探す

<details>
<summary>指示の下に何も出ない</summary>

1. 10 秒ほど待つ（出るまでは「訳しています…」の印が回ります）。
2. `/lingo` で claudelingo と「送った後の訳」がオンか確かめる。
3. コマンドや通知など、訳さない指示でないか確かめる（→ [送った後の訳](#送った後の訳)の細かい決まり）。
4. VS Code のチャット画面など、表示されない所でないか確かめる（→ [表示される場所](#表示される場所)）。
5. `/lingo` が無ければ、次の「`/lingo` が無い」へ。

</details>

<details>
<summary>/lingo が無い</summary>

1. `claude --version` が 2.1.287 以上か確かめる。
2. 導入の後、Claude Code を起動し直したか確かめる。
3. `/plugin` を開き、mod active の行に claudelingo があるか確かめる。

</details>

<details>
<summary>ターミナルでボタンを押しても何も起きない</summary>

1. `/tui fullscreen` で全画面表示にする（クラシック表示ではクリックできません）。
2. tmux なら `set -g mouse on`、iTerm2 なら Enable mouse reporting をオンにする。
3. `CLAUDE_CODE_DISABLE_MOUSE` か `CLAUDE_CODE_DISABLE_MOUSE_CLICKS` を設定していたら外す。

</details>

<details>
<summary>入力欄の上に帯が出ない</summary>

- 入力中の校正がオフ
- コマンドを打っている
- ✕ で消した後、まだ打っていない
- Claude Code のアンケートが出ている

</details>

<details>
<summary>［置換］を押しても変わらない</summary>

帯が出た後に入力欄を変えたためです（「入力が変わったので置換しませんでした」と出ます）。手を止めて、新しい帯が出てから押します。

</details>

<details>
<summary>🌐 が無い</summary>

- claudelingo がオフ
- コードだけのまとまり（訳す文が無い）

</details>

<details>
<summary>訳の語が押せない</summary>

- 単語の絵がオフ
- 母語への訳（押せるのは外国語への訳だけ）
- 記号だけの所

</details>

<details>
<summary>🔊 を押しても聞こえない</summary>

- 「読み上げできませんでした」と出たら → [表示から探す](#表示から探す)
- 何も出なければ、Mac の音量と出力先（Bluetooth など）を確かめる

</details>

<details>
<summary>音声入力が日本語で書き起こされる</summary>

音声入力の言語を、学ぶ言語にします（システム設定 › キーボード › 音声入力）。

</details>

<details>
<summary>訳や図解が消えた</summary>

`/clear`・`/resume`・`/branch`・起動し直しの後は消えます。戻せません。

</details>

<details>
<summary>草が増えない・多すぎる</summary>

- 増えない：学ぶ言語がラテン文字以外（その言語の語は数えない）、または claudelingo がオフ
- 多すぎる：ファイル名や URL の英字も数えます。`` ` `` で囲むと数えません

</details>

<details>
<summary>使用量の減りが早い</summary>

主に入力中の校正です（打つ手が止まるたびに 1 回）。モデルを haiku にする、反応の速さを遅くする、またはオフにします。

</details>

<details>
<summary>設定が初期値に戻った</summary>

claudelingo を 30 日以上使わないと消えます（→ [残るもの・消えるもの](#残るもの消えるもの)）。

</details>

### 表示から探す

| 表示 | 原因 | すること |
|---|---|---|
| 訳せませんでした：api-error（rate_limit） | 使用量の上限 | 枠が戻るまで待つ |
| 訳せませんでした：api-error（overloaded）／（server_error） | Claude 側の混雑・障害 | 少し待ってやり直す |
| 訳せませんでした：api-error（authentication_failed）など | ログイン・契約 | 本体で指示が通るか確かめ、だめなら `/login` |
| 訳せませんでした：api-error（model_not_found）／（invalid_request） | そのモデルが使えない | `/lingo` でモデルを変える |
| 訳せませんでした：api-error（max_output_tokens） | 長すぎる | 短く分ける |
| 訳せませんでした：empty-reply／aborted／format／api-error（unknown） | 一時的な失敗 | やり直す（下） |
| 訳せませんでした：（上のどれでもない文） | 依頼が受け付けられなかった（組織の制限など） | `/lingo` でモデルを変える |
| 描けませんでした：〈語〉 | 90 秒で描けない、上の原因、関係ない句や安全でない図解が返った | その語を 2 回押す（閉じて開く） |
| 書けませんでした | 60 秒で書けない、上の原因 | そのボタンを 2 回押す |
| コーチできませんでした：〈理由〉 | 「訳せませんでした」と同じ | もう一度 <kbd>Enter</kbd> |
| 読み上げできませんでした：〈理由〉 | 声の名前違い、その声が無い、Mac 以外、1 段落 4,096 字超 | 「声」を確かめる。空にすると既定の声 |
| 保存できませんでした：〈理由〉 | 設定をディスクに書けない | 空き容量と `~/.claude` の権限を確かめる |

**やり直し方**

- 送った後の訳：やり直せません。次に送る指示から訳します。
- 入力中の校正：また打って、手を止めます。
- 返事の訳：🌐 をもう一度押します。
- 発音記号：🔊 をもう一度押します。

### 解決しないとき

[GitHub の Issues](https://github.com/yodakeisuke/claudelingo/issues) に、表示された文言、`claude --version` の結果、ターミナルか Desktop か、を書いて送ってください。

# claudelingo

Claude Code をいつも通り使いながら、外国語が身に付く mod です。母語で打っても、指示のすぐ下にその外国語版が出ます。

## できること

- **送った指示の外国語版**：指示のすぐ下に、言い直した文（直した所は太字）と 💡 の学び
- **入力中の校正**：打つ手が止まると、入力欄の上に校正。直す所に赤い下線、「置換」で入れ替え
- **返事の訳**：返事の 🌐 を押すと、横のパネルに段落ごとの訳
- **単語の絵**：訳の語を押すと、その語の意味の芯が動く絵で出る（絵は Desktop のみ）。例文・類似表現・語源も
- **読み上げと話す練習**：🔊 で読み上げと発音記号、🎤 でお手本を声に出してコーチを受ける

あなたの指示も Claude の返事も、一文字も変えません。送信も返事も待たせません。

## 使い方

`/lingo` で設定を開きます。母語・学ぶ言語・今のレベル、機能ごとのオン・オフとモデル、読み上げの声を変えられます。初期値は 日本語 → 英語 です。

## Claude に送る文面

claudelingo は次の文面を、あなたの Claude Code と同じアカウント・同じ接続で Claude に送ります。ツールも会話履歴も持たない単発の呼び出しで、第三者には送りません。

| 送る文面 | いつ | 止めるには |
|---|---|---|
| 自分で送った指示 | 送るたび | 「送った後の訳」をオフ |
| 入力欄の下書き | 打つ手が止まるたび（送らずに消した文も含む） | 「入力中の校正」をオフ |
| 返事・押した語とその文・読み上げた文・練習で入れた文 | 押したときだけ | 押さない |

その分、使用量（レート制限や料金）を使います。`/lingo` でモデルを軽いもの（haiku）にすると抑えられます。

ディスクに残すのは `/lingo` の設定だけです。訳や絵はセッションの間だけ持ちます。

## インストール

mods に対応した Claude Code（CLI か Desktop の Code タブ）で動きます。ターミナルで次の 2 行を実行し、Claude Code を起動し直します。

```bash
claude plugin marketplace add yodakeisuke/claudelingo
claude plugin install claudelingo@claudelingo
```

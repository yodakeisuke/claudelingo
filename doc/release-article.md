最初に届ける相手：Claude Code で毎日開発している日本の開発者（入口のみ。文面は誰にでも当てはまる言葉にする）。
デモ：開発の依頼を、ほぼ日本語で、言い回しだけ英語を混ぜて書く。打っている間は入力欄の上に英語版と校正、送ると指示のすぐ下に英語版と 💡。メインの返事はそのまま。
文体：普段の X の口調。具体的な一場面から入り、決め台詞で締めない。各投稿 280（日本語は2で数える）以内。

## 1. フック＋動画＋導入

芯
- 共感：英語で書けば練習になるのに、作業優先で日本語で流している。
- 正体：日本語のまま打つと、指示のすぐ下に英語版が出る mod。本体は邪魔しない。
- 導入コマンド1つ。動画で見せる。

案（276/280）
```
Claude Code に「これなんで落ちてるの？ログ見て」とか毎日打ってるけど、英語で打てば勉強になるのになーとずっと思ってた。でも急いでるときは無理。

なので、日本語のまま打つと、送った指示のすぐ下に英語版が出る mod 作った。本体の作業は一切邪魔しない。

/plugin install claudelingo

[動画]
```

## 2. 作業を止めない

芯
- 本体（自分の依頼も Claude の返事も）は一切変えない。待ち時間も増えない。
- 英語版は指示の下に後から出るだけ。忙しいときは無視できる。

案（265/280）
```
一番こだわったのは、本体に一切手を入れてないところ。打った日本語はそのまま送られるし、Claude の返事もいつも通り日本語。待ち時間も増えない。

英語版は指示の下に後から出てくるだけなので、急いでるときは無視でいい。手が空いたときにチラ見する、くらいの距離感で使ってる。
```

## 3. 自分の言葉が教材、拙くても通じる

芯
- 出てくるのは、さっき自分が言いたかったことの英語版。だから入ってくる。
- AI 相手なら変な英語も日本語混じりも通じる。打っている間に自然な英語に直せるので、言える単語から少しずつ英語を増やせる。

案（280/280）
```
英語教材の例文は、自分が言いたいことじゃないから全然残らなかった。これは「さっき自分が言いたかったこと」の英語版なので、そのまま入ってくる。

日本語混じりや変な英語でも Claude には通じるし、打ってる間に入力欄の上で自然な英語に直せる。言える単語だけ英語にするところから始められる。
```

## 4. 行き先

芯
- 英語以外の言語でも使える。
- 気になった単語は、押すと意味の芯がアニメで見られる（Desktop）。
- 今は読み書きから。行き先は、声で Claude と英語でやりとりできること。
- 作り手もまだ途上。一緒に使ってほしい、感想がほしい。

案（278/280）
```
英語以外の言語でも使える。Desktop なら、気になった単語を押すと意味の芯がアニメで出てくる。

今は読み書きから。最終的には、声で Claude と英語でやりとりできるところまで持っていきたい。

自分もまだ日本語で打つことが多いので、一緒に使ってくれたら嬉しい。感想もらえたら全部読みます。
```

# リリース記事（X スレッド）

形式：4投稿以内のスレッド。1投稿目にデモ動画と導入コマンド。
最初に届ける相手：Claude Code で毎日開発している日本の開発者（入口のみ。文面は誰にでも当てはまる言葉にする）。
デモ：開発の依頼を、ほぼ日本語で、言い回しだけ英語を混ぜて書く。メインの返事はそのまま、横に同じやりとりの英語版が流れる。
文体：普段の X の口調。具体的な一場面から入り、決め台詞で締めない。各投稿 280（日本語は2で数える）以内。

## 1. フック＋動画＋導入

芯
- 共感：英語で書けば練習になるのに、作業優先で日本語で流している。
- 正体：日本語のまま打つと横に英語版が流れる mod。本体は邪魔しない。
- 導入コマンド1つ。動画で見せる。

案（266/280）
```
Claude Code に「これなんで落ちてるの？ログ見て」とか毎日打ってるけど、英語で打てば勉強になるのになーとずっと思ってた。でも急いでるときは無理。

なので、日本語のまま打つと横に英語版の会話が流れる mod 作った。本体の作業は一切邪魔しない。

/plugin install claudelingo

[動画]
```

## 2. 作業を止めない

芯
- 本体（自分の依頼も Claude の返事も）は一切変えない。待ち時間も増えない。
- 英語版は横に後から出るだけ。忙しいときは無視できる。

案（259/280）
```
一番こだわったのは、本体に一切手を入れてないところ。打った日本語はそのまま送られるし、Claude の返事もいつも通り日本語。待ち時間も増えない。

英語版は横で後から出てくるだけなので、急いでるときは無視でいい。手が空いたときにチラ見する、くらいの距離感で使ってる。
```

## 3. 自分の言葉が教材、拙くても通じる

芯
- 出てくるのは、さっき自分が言いたかったことの英語版。だから入ってくる。
- AI 相手なら変な英語も日本語混じりも通じる。言える単語から少しずつ英語を増やせる。

案（280/280）
```
英語教材の例文は、自分が言いたいことじゃないから全然残らなかった。これは「さっき自分が言いたかったこと」の英語版が出てくるので、そのまま入ってくる。

しかも相手は Claude なので、変な英語でも日本語混じりでも通じる。言える単語だけ英語にするところから、少しずつ割合を増やしていける。
```

# Sales playbook

## 刺すフレーズ

- 「これなんで落ちてるの？ログ見て」と送ると、すぐ下に "Why is this failing? Check the logs." が出る。
- 毎日 50 回打つ指示は、英語なら月 1500 本の英作文。今はそれを全部、日本語の中に捨てている。
- 英語で打とうとして手が止まり、結局日本語で打ち直す。あの 30 秒が、もう要らない。
- "fix" や "deploy" は書ける。でも「いい感じにして」「一旦これで」が英語で出てこない。その答えが毎回、自分の指示の下に出る。
- 例文集の "Where is the station?" は一生使わない。出てくるのは、さっき自分が Claude に頼んだことの英語。
- 「please この関数 refactor して」で Claude は普通に動く。英会話の先生相手なら固まる場面でも、気まずさがない。
- 打っている途中で、混ぜた英語が自然な形に直る。置換を押せば、それがそのまま送る文になる。
- 急ぐ日は全部日本語でいい。英語版が下に出るだけで、待ち時間も返事も変わらない。
- 返事を英語版で読んでみて、詰まった段落だけ「訳」を押す。

## よくある懸念と切り返し

**作業の邪魔にならない？**
本体には一切手を入れていない。打った指示はそのまま送られ、Claude の返事もそのまま。学習は別のモデル呼び出しで横で動き、本体の会話にも入らないので、待ち時間も増えない。

**返事が英語にされるのは困る。**
されない。返事はいつも通り。訳が欲しいときだけ「訳」を押す。

**英語が全然書けないけど使える？**
使える。最初は日本語だけでいい。送った指示の下に英語版が出るのを眺めるところから始められる。

**翻訳ツールで十分では？**
翻訳して貼るのは速いが、自分の力にはならない。これは自分が言いたかったことを、打ちながら自分で直していける。

**勉強する時間がない。**
時間は要らない。いつも通り Claude を使うだけ。急いでいるときは無視していい。

**余計なものが勝手に出てきてうるさくない？**
返事の訳、単語カード、読み上げは押したときだけ動く。自動で出るのは送った後の訳と入力中の校正だけで、どちらも `/lingo` で個別にオフにできる。

**コストや使用量は？**
正直に言うと増える。送った後の訳で指示ごとに 1 回、入力中の校正は打つ手が止まるたびに呼び出しが増える。返事の訳や単語カードなど、押して使う機能も押すたびに呼び出す。`/lingo` で軽いモデルを選ぶか、機能ごとにオフにできる。

**英語以外も学べる？**
学べる。母語と学ぶ言語は自由に書いて指定する。読み上げの声は英語の Samantha が初期値なので、他の言語は `/lingo` の「声」を変える。今の画面表示は日本語。

**ターミナルでも使える？**
使える。ただし全画面でないターミナルでは、ボタンが押せない。単語のアニメは Desktop のみで、ターミナルは説明文になる。

**話す練習はできる？**
まだ。今は読み書きと読み上げ（聞く）まで。話す練習は設計中。

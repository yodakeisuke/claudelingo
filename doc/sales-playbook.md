# Sales playbook

顧客にそのまま口で言う言葉。

## 刺すフレーズ

（）は使いどころ。

- 「英語の練習の機会、毎日何十回も捨ててますよ。Claude に日本語で打つたびに。」（最初の一言。失っていることに気づかせる）
- 「英語でやった方がいいのは分かってる。でも仕事は遅らせられない。その両方、取れます。」（相手の葛藤を言い当てる）
- 「仕事のスピードは一切落ちません。落ちたと感じたら、外してください。」（導入をためらう相手に）
- 「新しいアプリを開く必要はありません。いつもの Claude の中で起きます。」（学習アプリが続かなかった相手に）
- 「教材の例文って、人生で一度も言わないですよね。これは、今日あなたが言いたかったことしか出てきません。」（教材で挫折した相手に）
- 「日本語混じりの変な英語でも、Claude には通じます。だから今日から、言える単語だけ英語にできます。」（「まだ英語では打てない」と言われたら）
- 「人相手だと、間違えるのが恥ずかしい。AI 相手なら、何回間違えても誰も見ていません。」（話すのが苦手な相手に）
- 「ある日ふと、Claude に英語で打っている自分に気づく。そういう変わり方をします。」（締めの一言。行き先を描く）

## よくある懸念と切り返し

**作業の邪魔にならない？**
「なりません。あなたが打った文も、Claude の返事も、一文字も変えていません。英語は横に出るだけで、待ち時間も増えません。」

**返事まで英語になったら困る。**
「なりません。返事はいつも通りです。英語で読みたいときだけ、押せば出ます。」

**英語が全然書けない。**
「それで大丈夫です。最初は日本語で打つだけ。下に出る英語を眺めるところからで十分です。」

**どうせ続かない。**
「続ける努力が要らないんです。Claude を使っている限り、勝手に続きます。」

**時間がない。**
「時間は取りません。いつも通り Claude を使うだけです。急いでいる日は見なくていいです。」

**翻訳ツールでよくない？**
「翻訳は答えをもらうだけなので、力は付きません。これは、自分で混ぜて書いた英語を、打ちながら自分で直します。自分で直すから残ります。」

**余計なものが出てきてうるさくない？**
「返事の訳や単語の説明は、押したときしか出ません。自動で出るのは自分の指示の英語版と、打っている間の校正だけで、どちらも設定で消せます。」

**コストは？**
「正直に言うと、使用量は増えます。英語版や校正のために、裏で Claude を追加で呼ぶからです。軽いモデルに切り替えたり、要らない機能を切ったりして調整できます。」

**英語以外も学べる？**
「学べます。母語も学ぶ言語も自由に指定できます。読み上げの声だけは英語が初期値なので、そこは変えてください。画面の表示は今のところ日本語です。」

**ターミナルでも使える？**
「使えます。ただ、ボタンを押す機能は全画面のときだけです。単語のアニメは Desktop で見られます。」

**話す練習はできる？**
「できます。お手本の英文を声に出すと、コーチのようにフィードバックが返ってきます。Claude と声でそのまま会話するのは、まだ先です。」

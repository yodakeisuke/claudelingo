# 価値リスト

前提：Claude での作業は止まらないし、遅くもならない
前提：母語と学ぶ言語は自由記述で指定できる。初期値は日本語話者が英語を学ぶ
前提：段階は Claude に書く言語だけで決まる。製品は段階を区別せず、その日の余力で行き来できる

```
Step 1 日本語で書く
├ Writing   ① 送信後の訳　　　：送った日本語の英語版を見る
│           ① 打ちながらの訳　：送る前に英語版を見る
├ Reading   ② 返事の英語版　　：眺める
│           ③ 単語カード　　　：気になった単語の芯を掴む
├ Listening ④ 読み上げ　　　　：言いたかったことの英語を聞く
└ Speaking  未定
   ↓ 「こう言えばいいのかな」が溜まる

Step 2 混ぜて書く
├ Writing   ① 送信後の訳　　　：混ぜた文の自然な英語を見る
│           ① 打ちながらの校正：「こう言いたいの？」で一つずつ直す
├ Reading   ② 返事の英語版　　：詰まった所だけ日本語を見る
│           ③ 単語カード　　　：知らない単語の芯を掴む
├ Listening ④ 読み上げ　　　　：返事を聞く
└ Speaking  未定
   ↓ 知識と慣れが増える

Step 3 ほぼ英語で書く
├ Writing   ① 送信後の訳　　　：書いた英語の自然な形を見る
│           ① 打ちながらの校正：不自然な所だけ直す
├ Reading   ② 返事の英語版　　：英語だけで読む
│           ③ 単語カード　　　：ニュアンスの違いを掴む
├ Listening ④ 読み上げ　　　　：返事を英語で聞く
└ Speaking  未定

全 Step　⑤ 単語帳：見返す　⑥ 伸びを見る
```

価値

1. 自分が打った指示を、外国語ならどう言うかがわかる
2. Claude の返事を、外国語でも読める
3. コアイメージが、アニメーションで直感的にわかる
4. 外国語版を、その場で音声で聞ける
5. 使う中で覚えたいと思った単語やフレーズを、自分の単語帳・フレーズ集にためておける
6. 自分がどれだけ外国語で書けるようになったかがわかる

未決：いつ、どこに、どう見せるか

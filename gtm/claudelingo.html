ヘルプ

claudelingo

Claude Code にいつも通り指示を送るだけで、その指示の外国語版がすぐ下に出ます（初期設定は日本語 → 英語）。打ちながらの校正、返事の訳、単語のコアイメージの直感的な図解、読み上げと話す練習も、作業を止めずにその場で使えます。

  • 指示も返事も一文字も変わらない
  • 送信を待たせない
  • 定額プランなら追加料金なし（プランの範囲内）

最終更新：2026年10月4日

はじめて使う

必要なもの

  • Claude Code v2.1.287 以降（確かめ方：claude --version）
  • ターミナルの claude、または Desktop アプリの Code タブ
  • 読み上げを使うなら Mac

注意本体とは別に、プランの使用量を使います（API キーなら料金）。使うモデルは /lingo で変えられます。→ Claude に送るもの・モデルの選び方

導入する

  1. ターミナルで次の 2 行を実行します。
    ターミナル
    claude plugin marketplace add yodakeisuke/claudelingo
claude plugin install claudelingo@claudelingo

    Successfully installed plugin: claudelingo@claudelingo (scope: user) と出れば完了です。ターミナルにも Desktop にも入ります。

  2. Claude Code を起動し直します（開いているセッションなら /reload-plugins でも可。Desktop は新しいセッションを始めます）。
  3. 何か指示を送ります。数秒〜10 秒で、すぐ下に英語が出れば使えています。

ヒント英語以外を学ぶなら、/lingo で「学ぶ言語」を変えます（→ 設定を変える）。

画面のどこに何が出るか

右の説明を押すと、その機能の使い方へ移ります。

  • 自動で出るのは「送った後の訳」と「入力中の校正」だけです。ほかは押したときだけ動きます。
  • 🔊 は、押すとその文を読み上げます（→ 読み上げ）。設定と草は /lingo で開きます。
  • ターミナルでボタンをクリックできるのは、全画面表示（/tui fullscreen）のときだけです（→ 表示される場所）。

機能の使い方

送った後の訳 自動

送った指示のすぐ下に、外国語での言い方と学びが出ます。

知っておくこと

  • 母語の部分は訳され、外国語で書いた部分は自然な形に直されます。
  • 出るまで数秒〜10 秒かかります。それまでは何も表示されません。
  • 外国語版の語を押すと、単語の絵が開きます。
細かい決まり
訳す指示自分で送った指示（ターミナル・Desktop・Remote Control）。/tmp を見て のように / で始まっても、コマンドでなければ訳す
訳さない/clear などのコマンド、通知、ほかのエージェントやセッションからのメッセージ、オフの間に送った指示
長い指示数十秒かかることがある（opus も同じ）
貼り付け・コード訳では [...] になる
改行なくなり、ひと続きで出る
失敗したとき「訳せませんでした：理由」が出る。やり直しはできない（→ 表示から探す）
同じ指示をもう一度送る今の設定で訳し直す
消す・コピーする出ている訳だけは消せない。Desktop では文字を選べない

入力中の校正 自動

送る前に、入力欄の上で外国語の言い方を確かめて直せます。言えない所は母語のまま打てば、訳して埋めます。

使い方

  1. 入力欄に打って、手を止めます。数秒で入力欄の上に帯が出ます。
  2. 直すなら、次のどちらかです。
    • 赤い下線の語を自分で直す（身に付く）。直すと次の誤りに下線が移ります。
    • ［置換］を押す（速い）。入力欄が帯の文に丸ごと入れ替わります。元に戻すボタンはありません。
  3. Enter で送ります。帯は消えます。帯だけ消すなら ✕ を押します。
細かい決まり
帯が出るまで打つ手が「反応の速さ」（初期 0.5 秒）止まったら頼む。また打つと、その依頼は取り消す
新しい帯が出るまで前の帯が残る
［置換］が効かない帯の後に入力欄を変えたとき。新しい帯を待ってから押す
コマンドを打っている間校正しない（/ の後がコマンド名の書き出しのとき）
入力欄を空にした帯が消える
通知などで送られた帯は残る（自分で送ると消える）
アンケートが出ている校正の帯も練習の帯も出ない
練習の帯もあるとき練習の帯の下に出る
失敗したとき帯に「訳せませんでした：理由」。また打つと頼み直す
ターミナルのキーctrl+x tab で帯へ、Tab で選んで Enter。たたむのは ctrl+x ctrl+a か [-]

返事の訳 🌐 を押す

Claude の返事を段落ごとに訳して、訳のパネルに出します。返事そのものは変わりません。

使い方

  1. 返事の下の 🌐 を押します。
  2. 「訳しています…」の後、数秒〜数十秒で訳が出ます。
  3. 閉じるときは、パネルの ✕ を押します（ターミナルは ctrl+x x でも）。
細かい決まり
訳す向き主に母語の返事は外国語へ、主に外国語の返事は母語へ（自動）
同じ返事をもう一度訳し直さず、すぐ出す。失敗していたら訳し直す
言語を変えた後押すと、新しい言語で訳し直す
ほかの返事の 🌐パネルの中身が入れ替わる（一度に 1 つ）
🌐 が無いまとまりコードだけのまとまり
語を押せるとき外国語への訳で、単語の絵がオンのとき
パネルの位置ターミナルは、全画面表示で幅 110 桁以上なら右、それ以外は入力欄の上
/clear などの後パネルは開いたまま「返事の 🌐 を押すと、ここに訳が出ます」に戻る
失敗したとき「訳せませんでした：理由」。🌐 を押し直すと訳し直す

単語の絵 語を押す

訳の中の語を押すと、その語のコアイメージを動く図解で直感的に見られます。例文・類似表現・語源も開けます。

使い方

  1. 訳の中の語を押します。押せる語は薄い字で出ています。
  2. 「コアイメージを描画中…」の後、20〜60 秒ほどで出ます。待つ間も 🔊・🎤・［例文］などは押せます。
  3. 閉じるときは、同じ語をもう一度押します。
細かい決まり
句になるとき句の一部なら句で出る（carry → carry on）。句のどの語を押しても閉じる
押せる語送った後の訳と、外国語への返事の訳。記号だけの所は押せない。濃い字は直した語と、開いている語
いくつも押す押した順に下へ並ぶ
もう一度開く同じ文の同じ語なら、描き直さずすぐ出る（このセッションの間）
同じ文面の指示が 2 つ押した方の下にだけ出る
ターミナル図解の代わりに 1 行（句・発音記号・一文・🔊 🎤）。［拡大］はない
［拡大］図解を大きくする。［縮小］で戻す（Desktop のみ）
［例文］場面の違う例文 3 つ。それぞれ訳と、なぜこの語かの一言つき。例文の 🔊 で発音記号も出る
［類似表現］言い換え 2〜3 個と、それを選ぶ場面
［語源］部品の元の意味と、今の意味へのつながり。定説がなければ、そう書く
［例文］などの開閉「書いています…」の後、長くて 60 秒で出る。もう一度押すと閉じ、開き直すと書き直す（使用量も使う）
単語の絵を閉じる開いていた［例文］なども閉じる
失敗したとき「描けませんでした：carry」「書けませんでした」（→ 表示から探す）

読み上げ 🔊 を押す

押した所の文を、Mac の声で読み上げます。

🔊 の場所読むもの発音記号
送った後の訳の横訳の文訳の下に出る
訳のパネルの下外国語の段落を順に段落ごとに出る
単語の絵句もとからある
例文その例文例文の下に出る
練習の帯の［🔊 お手本］お手本—

知っておくこと

  • 声は /lingo の「声」で選びます（初期は Samantha）。英語以外なら、その言語の Mac の声の名前を入れます。
  • 続けて押すと順番に読みます。途中では止められません。
  • 読めないときは「読み上げできませんでした：理由」と出ます。
細かい決まり
声の名前システム設定 › アクセシビリティ › リーダーと読み上げ（macOS 15 以前は「読み上げコンテンツ」）で確かめ、追加できる。空にすると既定の声
発音記号最初の 1 回だけ書く（「発音記号を書いています…」）。書けなければ消え、次に押すと書き直す
音の出る所Claude Code を動かしている Mac
長さ1 段落 4,096 字まで

話す練習 🎤 を押す

お手本を声に出して言うと、伝わらなかった音と直し方をコーチが教えます。

準備Mac の音声入力をオンにし、言語に学ぶ言語を加えます（システム設定 › キーボード › 音声入力）。マイクの音は claudelingo に届かず、使うのは書き起こした文字だけです。

使い方

  1. 送った後の訳か単語の絵の 🎤 を押します。入力欄の上に練習の帯が開きます。
  2. 練習の欄へ移ります（Desktop は最初から。ターミナルは ctrl+x tab）。
  3. 音声入力を始め、お手本を声に出して言います。
  4. Enter を押します。数秒で、聞き取りと 💡 が出ます。
細かい決まり
音声入力の始め方システム設定 › キーボード › 音声入力 にあるショートカット（fn キー 2 回など）
欄が空で Enter何も起きない
キーボードで打った打った文をお手本と比べる
閉じる✕、または同じ 🎤 をもう一度
別の 🎤帯の中身が入れ替わる。届く前のコーチは捨てる
欄の文の行き先会話には入らない。コーチのため Claude に送る
claudelingo をオフ帯が消える
失敗したとき「コーチできませんでした：理由」。もう一度 Enter

草 /lingo の下

自分で書いた外国語の語数が、1 日 1 マスで並びます。GitHub の草と同じ見方です。

0 語　1〜99 語　100〜249 語　250 語以上

数えるもの

  • claudelingo がオンの間に、自分で送った指示
  • その中のラテン文字の語（don't は 1 語）
  • ファイル名や URL の英字も

数えないもの

  • ` で囲んだ所・コードブロック・貼り付け
  • /clear などのコマンド
  • 日本語など、ラテン文字以外

補足学ぶ言語がラテン文字以外（中国語・韓国語・ロシア語など）なら、その言語で書いた語は数えません。草に出るのは、ラテン文字の語だけです。

細かい決まり
1 マスの日付その PC の日付。縦は日曜〜土曜
並ぶ期間ターミナルは幅に入るだけの週、Desktop は 1 年分
記録PC に残り、すべてのセッションの分を足す（ほぼ同時に送った分は、片方が数えられないことがある）。画面から消す方法はない（→ 残るもの・消えるもの）

設定と管理

設定を変える /lingo

初期設定（日本語 → 英語）のままでも使えます。

使い方

  1. /lingo を送ります。Claude が作業中でも開けます。
  2. 変えます。ボタンは押すと、文字の項目は Enter で保存されます。
  3. Esc で閉じます。

知っておくこと

  • 次の訳から効きます。出ている訳は変わりません。
  • この PC のすべてのセッション・プロジェクトで共通です。
  • 保存できないと赤字で「保存できませんでした：理由」と出て、値は変わりません。
項目ごとの決まり
母語・学ぶ言語空のまま Enter しても変わらない
画面の言葉母語が Japanese か 日本語 なら日本語。ほかの言語名にすると英語になる
今のレベル訳・ヒント・図解・コーチの難しさがこれに合う。空欄なら伝えない
基本のモデル送った後の訳・返事の訳・発音記号・コーチ・例文などに使う（→ モデルの選び方）
反応の速さ0.3〜2 秒。［-］［+］で 0.1 秒ずつ。範囲外は端に丸め、数でない入力は無視
声空にすると Mac の既定の声
オフにしたまとまり見出しだけになる。claudelingo をオフにすると、下の項目と草が隠れる
文字の項目Enter を押さずに離れると保存されない
ターミナルのキーTab で項目を移り、Enter で押す・確定

次のときに Claude を呼び、そのたびに使用量を使います。

困ったとき

症状から探す

指示の下に何も出ない
  1. 10 秒ほど待つ（出るまでは何も表示されません）。
  2. /lingo で claudelingo と「送った後の訳」がオンか確かめる。
  3. コマンドや通知など、訳さない指示でないか確かめる（→ 送った後の訳の細かい決まり）。
  4. VS Code のチャット画面など、表示されない所でないか確かめる（→ 表示される場所）。
  5. /lingo が無ければ、次の「/lingo が無い」へ。
/lingo が無い
  1. claude --version が 2.1.287 以上か確かめる。
  2. 導入の後、Claude Code を起動し直したか確かめる。
  3. /plugin を開き、mod active の行に claudelingo があるか確かめる。
ターミナルでボタンを押しても何も起きない
  1. /tui fullscreen で全画面表示にする（クラシック表示ではクリックできません）。
  2. tmux なら set -g mouse on、iTerm2 なら Enable mouse reporting をオンにする。
  3. CLAUDE_CODE_DISABLE_MOUSE か CLAUDE_CODE_DISABLE_MOUSE_CLICKS を設定していたら外す。
入力欄の上に帯が出ない
  • 入力中の校正がオフ
  • コマンドを打っている
  • ✕ で消した後、まだ打っていない
  • Claude Code のアンケートが出ている
［置換］を押しても変わらない

帯が出た後に入力欄を変えたためです。手を止めて、新しい帯が出てから押します。

🌐 が無い
  • claudelingo がオフ
  • コードだけのまとまり（訳す文が無い）
訳の語が押せない
  • 単語の絵がオフ
  • 母語への訳（押せるのは外国語への訳だけ）
  • 記号だけの所
🔊 を押しても聞こえない
  • 「読み上げできませんでした」と出たら → 表示から探す
  • 何も出なければ、Mac の音量と出力先（Bluetooth など）を確かめる
音声入力が日本語で書き起こされる

音声入力の言語を、学ぶ言語にします（システム設定 › キーボード › 音声入力）。

訳や図解が消えた

/clear・/resume・/branch・起動し直しの後は消えます。戻せません。

草が増えない・多すぎる
  • 増えない：学ぶ言語がラテン文字以外（その言語の語は数えない）、または claudelingo がオフ
  • 多すぎる：ファイル名や URL の英字も数えます。` で囲むと数えません
使用量の減りが早い

主に入力中の校正です（打つ手が止まるたびに 1 回）。モデルを haiku にする、反応の速さを遅くする、またはオフにします。

設定が初期値に戻った

claudelingo を 30 日以上使わないと消えます（→ 残るもの・消えるもの）。

  • 入力中の校正：また打って、手を止めます。

Help

claudelingo

Keep using Claude Code as usual, and the version of each prompt in the language you're learning appears right below it. Proofreading while you type, reply translations, intuitive diagrams of a word's core image, read-aloud, and speaking practice are there too, without stopping your work.

  • Your prompts and Claude's replies stay exactly as they are
  • Sending is never delayed
  • No extra cost on a subscription plan (within your plan's usage)

Last updated: October 4, 2026

Getting started

What you need

  • Claude Code v2.1.287 or later (check with claude --version)
  • claude in a terminal, or the Code tab of the Desktop app
  • A Mac, if you want read-aloud

Heads-upIt uses your plan's usage, on top of your main work (or per-token charges with an API key). You can change the model in /lingo. → What is sent to Claude · Choosing a model

Install

  1. Run these two lines in your terminal.
    Terminal
    claude plugin marketplace add yodakeisuke/claudelingo
claude plugin install claudelingo@claudelingo

    You're done when you see Successfully installed plugin: claudelingo@claudelingo (scope: user). It's installed for both the terminal and Desktop.

  2. Restart Claude Code (in an open terminal session, /reload-plugins also works; in Desktop, start a new session).
  3. Set your languages before your first prompt. Send /lingo. The defaults are Japanese → English, so the panel first appears in Japanese. In the first field, 母語 (Native), type your language, for example English, and press Enter: the panel switches to English. Then set Learning, for example Spanish.
  4. Send any prompt. If its version in your learning language appears right below it within a few seconds to 10 seconds, it works.

What shows up where

The examples on this page are from a native English speaker learning Spanish. Press a label on the right to jump to that feature.

  • Only After sending and While typing run on their own. Everything else runs only when you press it.
  • 🔊 reads that text aloud (→ Read aloud). Settings and the writing graph open with /lingo.
  • In the terminal, buttons can be clicked only in fullscreen rendering (/tui fullscreen) (→ Where it shows).

Troubleshooting

By symptom

Nothing appears under my prompt
  1. Wait about 10 seconds (nothing shows until it's ready).
  2. In /lingo, check that claudelingo and After sending are on.
  3. Check that it isn't a prompt that's never translated, such as a command or a notification (→ the details under After sending).
  4. Check that you aren't somewhere it doesn't show, such as the VS Code chat panel (→ Where it shows).
  5. If /lingo doesn't exist, see the next item.
There's no /lingo
  1. Check that claude --version is 2.1.287 or later.
  2. Check that you restarted Claude Code after installing.
  3. Open /plugin and check that claudelingo is on its "mod active" line.
Clicking buttons in the terminal does nothing
  1. Switch to fullscreen rendering with /tui fullscreen (classic rendering can't click).
  2. In tmux, set set -g mouse on; in iTerm2, turn on Enable mouse reporting.
  3. Unset CLAUDE_CODE_DISABLE_MOUSE or CLAUDE_CODE_DISABLE_MOUSE_CLICKS if you set them.
No band above the input
  • While typing is off
  • You're typing a command
  • You closed it with ✕ and haven't typed since
  • A Claude Code survey is showing
Replace does nothing

You changed the input after the band appeared. Pause, wait for a new band, then press it.

There's no 🌐
  • claudelingo is off
  • The block is code only (nothing to translate)
I can't press words in a translation
  • Word pictures is off
  • It's a translation into your native language (only translations into your learning language can be pressed)
  • It's only symbols
I hear nothing when I press 🔊
  • If "Couldn't read aloud" appears → By message
  • If nothing appears, check your Mac's volume and output (Bluetooth and so on)
Dictation types in my native language

Set Dictation's language to your learning language (System Settings › Keyboard › Dictation).

Translations or pictures disappeared

They're gone after /clear, /resume, /branch, or a restart, and can't be brought back.

The writing graph doesn't grow, or grows too much
  • Doesn't grow: your learning language isn't written in Latin letters (words in it aren't counted), or claudelingo is off
  • Too much: file names, URLs, and native-language words in Latin letters count too. Text in ` doesn't count
Usage goes down fast

Mostly While typing (one call every time you pause). Pick haiku, lengthen the Delay, or turn it off.

My settings went back to the defaults

They're deleted if you don't use claudelingo for 30 days (→ What is kept).

How to retry

  • After sending: can't be retried. The next prompt you send is translated.
  • While typing: type again and pause.
  • Reply translation: press 🌐 again.
  • Pronunciation: press 🔊 again.

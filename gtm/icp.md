# ICP 定義

## 一言で
Claude を毎日使っている。外国語でやりとりすれば勉強にもなるのに、と思いつつ、作業効率は落としたくないので母語で使っている人。

## 抱えている矛盾
- Claude には毎日、何十回も指示を書いている。そのどれもが外国語の練習になり得る。
- でも、仕事の効率を落としてまではできない。急ぎのときは迷わず母語で書く。
- 結果、練習の機会は毎回、母語の中に消えている。

## 他の手段では解決しない理由
- 学習を「わざわざやる」のは腰が重い。
- 人と話す練習は、予定合わせ、お金、気疲れとコストが高い。
- 翻訳して貼るのは速いが、自分の力にはならない。
- 一方で Claude とは、すでに毎日、追加コストなしで会話している。
- しかも AI 相手なら、拙くても、母語混じりでも通じる。恥も気遣いもいらない。

## 外国語の力
ゆっくりなら読める。書くのは遅い。聞くことや話すことは、もっと苦手。

## 進み方
Claude に書く言語が、母語 → 混ぜて書く → ほぼ外国語、と移っていく。その日の余力で行き来する。
- 母語から混ぜるまで：引っ掛かりがない。外国語でどう言うか思いつかない。
- 混ぜるからほぼ外国語まで：語彙と慣れが足りない。

## 欲しいもの
いつも通り Claude を使うだけで、外国語で会話できる自分になっていく。
まずは読み書きから。最後は、声でも Claude と外国語でやりとりできるようになりたい。

## 譲れないこと
Claude でやりたいことの流れを、止めない。遅くもしない。

## 典型例
日本人の開発者。いずれは開発も英語で Claude と進めたいが、いきなりは無理。まずは日本語で指示しながら、「英語ならこう言う」を知りたい。

## 対象外
- 学習のために、まとまった時間を取りたい人
- Claude をほとんど使わない人

## 検証すべき仮説
1. 自分が書いたことの外国語版を、作業の横で見るだけで、学びになると感じる。
2. 急ぎでない場面から外国語を混ぜ始め、その割合が増えていく。
3. メインを一切邪魔しないことが、使い続ける決め手になる。
4. 上達の実感は付随的だが、続ける理由として効く。

## 最初に届ける相手
Claude Code で毎日開発している日本の開発者。入口として選ぶだけで、対象は一般の Claude ユーザーまで広げる。

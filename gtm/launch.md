# ローンチ

届ける相手と言葉は [Sales playbook](sales-playbook.md) に。

## 出す前にやること
- repo を public にする
- 導入を決める。今は clone して `--plugin-dir`（README の通り）。マーケットプレイスを置けば `/plugin install` の 1 行にできる
- Desktop でデモ動画を撮る（単語の絵が動くのは Desktop だけ）

## リリース記事（X スレッド）

形式：4投稿以内。1投稿目にデモ動画と導入先。
デモ：開発の依頼を、ほぼ日本語で、言い回しだけ英語を混ぜて書く。打っている間は入力欄の上に英語版と校正、送ると指示のすぐ下に英語版と 💡。メインの返事はそのまま。最後に返事の 🌐 と単語の絵。
文体：普段の X の口調。具体的な一場面から入り、決め台詞で締めない。各投稿 280（日本語は2で数える）以内。

### 1. フック＋動画＋導入

```
Claude Code に「これなんで落ちてるの？ログ見て」とか毎日打ってるけど、英語で打てば勉強になるのになーとずっと思ってた。でも急いでるときは無理。

なので、日本語のまま打つと、送った指示のすぐ下に英語版が出る mod 作った。本体の作業は一切邪魔しない。

https://github.com/yodakeisuke/claudelingo

[動画]
```

### 2. 作業を止めない

```
一番こだわったのは、本体に一切手を入れてないところ。打った日本語はそのまま送られるし、Claude の返事もいつも通り日本語。待ち時間も増えない。

英語版は指示の下に後から出てくるだけなので、急いでるときは無視でいい。Claude が考えてる間にチラ見する、くらいの距離感で使ってる。
```

### 3. 自分の言葉が教材、拙くても通じる

```
英語教材の例文は、自分が言いたいことじゃないから全然残らなかった。これは「さっき自分が言いたかったこと」の英語版なので、そのまま入ってくる。

日本語混じりや変な英語でも Claude には通じるし、打ってる間に入力欄の上で自然な英語に直せる。言える単語だけ英語にするところから始められる。
```

### 4. 読む・聞く・話すも、押したときだけ

```
返事は 🌐 で英語版を横に出せるし、気になった単語は意味の芯が動く絵で出る。🔊 で読み上げ、🎤 で声に出すと伝わらなかった音を教えてくれる。どれも押したときだけ。英語で打った語数は草になる。

英語以外でも使える。自分もまだ日本語が多いので、一緒に使ってくれたら嬉しい。
```

## 出した後に確かめること
記事への返信と、使い続けた人の声で確かめる。利用データは取らない。
1. 自分が書いたことの外国語版を、作業の横で見るだけで、学びになると感じる
2. 急ぎでない場面から外国語を混ぜ始め、その割合が増えていく（本人の草に出る）
3. メインを一切邪魔しないことが、使い続ける決め手になる
4. 上達の実感は付随的だが、続ける理由として効く

# リリース記事（X スレッド）

親投稿 1 本と、1 投稿 1 メッセージの子投稿 5 本。子投稿は全部 280（日本語は 2 で数える）以内で、折りたたまれない。

## 親投稿

```
Claude Code を使うついでに、外国語の読む・書く・聞く・話すを練習できるmod「claudelingo」をリリースしました！
普段やり取りをしている中で「これ本当は英語でやったらすげえ勉強になるのにな、LLM相手だから気兼ねないし」と思ってました。
が、めんどいし、そもそもなんて言っていいのかわからない、そもそも仕事だったらそっちの早さが優先されるとか、わざわざやらないです。

って時に、本流チャットを一切邪魔せず、サイドで 段階的に 学習できるようにしました。
コアイメージの図解の動的生成や入力欄でのリアルタイム校正とか LLMならではの学習もできて自分ではかなりいいと思っています

claude plugin marketplace add yodakeisuke/claudelingo
claude plugin install claudelingo@claudelingo
```

添付：全体の動画 1 本（普段の作業の横で、読む・書く・聞く・話すが自然に起きているのが伝わるもの）と、画像 2 枚。

画像 2 枚（見出し／補足）
1. 定額プランのまま／追加料金なし。使用量が気になれば設定で軽いモデルに
2. Claude が分かる言語ならどれでも／母語も学ぶ言語も、設定に書くだけ

## 子投稿

### 1（252）

```
✍️ さっき言いたかったことの英語は、頭に入る
送った指示の英語版

指示を英語で送りたくても、どう言うか見当も付かない、というときは日本語で送って OK。送信後、自分の指示の英語版が下に出ます。回答待ちに読んでみましょう。💡 には、次に使える言い回しが一言。
```

画像 2 枚（見出し／補足。本文に書けなかったことだけ）
1. 指示も返事も、一文字も変わらない／作業も遅くならない
2. 日本語だけ → 言える所だけ英語 → ほぼ英語／その日の余力で行き来していい。切り替える設定もない

### 2（275）

```
✍️ 英語で打つと、送る前にリアルタイム校正
入力中の校正

慣れてきたら、英語（日本語混じりでも OK）で指示してみましょう。打つ手を止めると、間違えた語に赤線が付き、「置換」で直してから送れます。直さずに送っても、英語版では直った所が太字になるので、どこが変だったか分かります。
```

画像 2 枚
1. 変な英語のまま送っても、Claude には通じる／通じたかは、Claude がその通りに動いたかで分かる
2. 💡 は、なぜそう直すかを日本語で／似た指示を毎日打つから、勝手に復習になる

### 3（238）

```
📖 知りたかった答えなら、英語でも読める
返事の対訳

Claude の返事は、🌐 を押すと段落ごとに横へ英語版が出ます（英語の返事なら日本語訳）。自分の仕事の話なので文脈で読めるし、詰まった所だけ日本語を見ればいい。訳の単語を押せばコアイメージも。
```

画像 2 枚
1. 訳は、押した返事だけ／コードやファイル名は訳さずに残る
2. 英語で頼むようになっても、同じ 🌐／訳のパネルから 🔊 で読み上げも

### 4（278）

```
📖 どの単語でも、意味が図になって動く
コアイメージの動的生成

単語を押すと、その文での意味を、LLM がコアイメージの図解にしてその場で動かします。参考書のコアイメージは静止画で、載ってる単語だけでした。前置詞や句動詞みたいに、訳語だと掴みにくい語ほど効きます（動くのは Desktop）。
```

GIF 1 本
1. 句動詞や熟語は、まとまりで 1 枚に／例文・言い換え・語源も、その意味で作る

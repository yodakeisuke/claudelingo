# Sales playbook

## 誰に

Claude を毎日使っている。外国語でやりとりすれば勉強にもなるのに、と思いつつ、作業効率は落としたくないので母語で使っている人。

- 最初に届ける相手：Claude Code で毎日開発している日本の開発者。いずれは開発も英語で進めたいが、いきなりは無理。入口として選ぶだけで、対象は一般の Claude ユーザーまで広げる
- 対象外：学習のためにまとまった時間を取りたい人。Claude をほとんど使わない人

その人の今
- Claude には毎日、何十回も指示を書く。どれも練習になり得るが、急ぎのときは迷わず母語で書く。練習の機会は毎回、母語の中に消えている
- ゆっくりなら読める。書くのは遅い。聞く・話すはもっと苦手
- 欲しいのは、いつも通り Claude を使うだけで、外国語で会話できる自分になっていくこと。最後は声でも
- 譲れないのは、Claude でやりたいことの流れを止めない、遅くもしないこと

## 言うこと

顧客にそのまま口で言う言葉。

つかみ
- 「Claude に日本語で打つたび、英語の練習を一回捨てています。」
- 「仕事の速さはそのまま。英語だけ伸びます。」

これまでとの違い
- 学習アプリ派に：「アプリは開かないと続かない。これは、Claude を使った日が全部、英語の日。」
- 翻訳ツール派に：「翻訳は何年使っても書けるようにならない。これは使うほど書ける。」
- 教材派に：「教材の例文は一生使わない。これは明日も打つ、自分の文。」
- 添削派に：「添削は何日も待つ。これは送る前に、理由付きで直せる。」
- 辞書派に：「辞書は訳語を並べるだけ。これは語の芯を、動く絵で見せる。熟語も、部品が合わさるのを見るだけ。」
- 発音アプリ派に：「発音アプリは点数だけ。これは、どの音をどう直すかまで。」
- 英会話派に：「英会話は月謝を払って週一回、緊張して。これは定額プランのまま、毎日何十回、気兼ねなく。」

なぜ身に付くか（根拠を聞かれたら括弧の名前）
- 「自分が言おうとしたことは忘れにくい。しかも似た指示を毎日打つから、勝手に復習になる。」（自己関連付け効果、分散学習）
- 「言おうとして詰まった直後に答えを見るから、刺さる。」（アウトプット仮説）
- 「Claude がその通りに動いたら、通じた証拠。採点するのは仕事そのもの。」（アウトプット仮説の検証）
- 「Claude が考えている間に読めるから、待ち時間が学ぶ時間になる。」（MIT の Wait-Learning）

締め
- 「気づいたら、Claude に英語で打っています。」

## よくある懸念と切り返し

- 作業の邪魔では？：「指示も返事も一文字も変えません。待ち時間も増えません。遅くなったと感じたら外してください。」
- 返事が英語になる？：「なりません。読みたいときだけ押せば出ます。」
- 英語が書けない：「日本語のままで大丈夫です。英語は下に出ます。」
- 恥ずかしい：「相手は AI です。変な英語でも通じるし、誰も見ていません。」
- うるさくない？：「自動で出るのは英語版と校正だけ、どちらも消せます。他は押したときだけです。」
- コストは？：「定額プランなら追加の支払いはありません。使用量の枠は多めに使うので、軽いモデルや機能オフで調整できます。」
- 日本人向け？英語だけ？：「言語は選びません。どの母語からどの言語でも、書くだけで指定できます。読み上げの声だけ変えてください。画面の文字は今は日本語です。」
- ターミナルは？：「使えます。ボタンは全画面のときだけ、動く絵は Desktop だけです。」
- 話す練習は？：「お手本を声に出すと、伝わらなかった音を教えてくれます。声での会話はまだ先です。」
- 伸びてるかわかる？：「`/lingo` を開くと、英語で打った語数が毎日の草で出ます。」
